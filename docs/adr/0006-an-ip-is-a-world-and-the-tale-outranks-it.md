# An IP is a World, and the tale outranks it

Seth decided this on 2026-10-27, in the grill on reworking Spark (New tale). The words are
GLOSSARY.md's.

## Why

A tale set in an existing story or game had no way to know it. Kia's *The Lands Between* carried
"Elden Ring" in one field, and that one line was all the model was told about the setting; its 73
threads were written by hand and reached the model only when a word woke them. The same tale gives
Morgott a queen, which the game does not, and the contradiction check flagged it at 90% and a
correction rewrote her prose to match the game.

## The decision

**An IP becomes a World.** Naming an IP when a tale is started makes a World of its people and
places, looked up online, which the writer ticks before it is made. The tale follows that World,
live. A second tale in the same IP follows the same World instead of looking everything up again.
Worlds are per writer: Kia's Elden Ring is hers and Seth's is his.

**The tale outranks its World.** Where the tale says something different (its premise, or its own
thread of the same name), the tale's version is the true one, for the model and for the
contradiction check alike. The check flags a contradiction with the tale, never with the World the
tale has chosen to differ from.

## Considered and not chosen

- **The IP's people as this tale's threads only**: every tale in the same IP looks it all up again,
  and the copies drift.
- **A new word ("Source") that a World is made from**: two words for one thing a writer does.
- **The World outranks the tale**: what the check does today, and the reason Kia's tale was being
  corrected back to canon. Writing a different version of an IP is the main reason to write in one.
- **Worlds shared between writers**: a new kind of access across accounts, decided separately if
  ever.

## Consequences

- A followed World's person can be pinned into a tale's scene without being copied (pins today
  hold only the tale's own threads).
- The contradiction check needs the tale's premise and own threads to rank above the World's when
  it reads a passage.
- A tale that followed nothing can later be offered "Make a World of this IP and follow it" from its
  settings, using the same World maker.
